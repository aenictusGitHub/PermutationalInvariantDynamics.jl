# Dissipative LMG model from PRA 110, 062208

Source: [`pra110_062208_lmg.jl`](pra110_062208_lmg.jl)

## Model

The example implements the finite-size qubit model studied by Pausch *et al.*:
a Lipkin-Meshkov-Glick interaction proportional to `Jx^2 - Jy^2`, together
with individual and collective dissipation. It uses `N = 8`, `V = 1`,
`γc = 0.2`, and scans the individual rate `γi` across the mean-field crossover.

## Solution

The constructor in `paper_models.jl` fixes the article's normalization. The
script calls `compile(...; backend=:sparse)` once per parameter point,
obtains a trace-normalized `PIState` with
`stationary_state(...; algorithm=DirectAlgorithm())`, and evaluates the global
finite-size gap with `pi_liouvillian_gap`. A `CollectiveObservablePlan` for
`Jz` contracts the polarization directly from the Schur blocks. The result is
compared with the paper's mean-field equation.

For larger systems, let `compile` select its backend and use
`GMRESAlgorithm()` for the stationary state. The Krylov gap routine avoids a
complete diagonalization when only the slowest modes are required.

## Run

```sh
julia --project=. examples/pra110_062208_lmg.jl
```

The mean-field expression is a thermodynamic benchmark, not an exact `N = 8`
answer. The finite-size discrepancy and nonzero gap are therefore physical.
